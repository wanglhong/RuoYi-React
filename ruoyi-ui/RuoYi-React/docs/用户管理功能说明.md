# 用户管理功能说明

## 功能概述

实现了系统管理模块的用户管理功能，包括用户列表、新增、编辑、删除、状态修改和重置密码等核心功能。

---

## 已实现功能

### 1. 用户列表 ✅
- 分页展示用户列表
- 显示用户编号、用户名称、昵称、部门、手机号码、状态、创建时间
- 支持多选操作
- 响应式表格布局

### 2. 搜索功能 ✅
- 用户名称搜索
- 手机号码搜索
- 状态筛选
- 创建时间范围筛选
- 搜索条件重置

### 3. 新增用户 ✅
- 用户昵称（必填）
- 用户名称（必填，只能包含字母数字下划线）
- 用户密码（必填）
- 手机号码
- 邮箱
- 用户性别
- 状态
- 备注

### 4. 编辑用户 ✅
- 编辑用户信息
- 用户名称不可修改
- 密码留空表示不修改

### 5. 删除用户 ✅
- 单个删除
- 批量删除
- 删除确认对话框
- 超级管理员（userId=1）不可删除

### 6. 状态修改 ✅
- 开关切换用户状态
- 状态：正常/停用
- 超级管理员状态不可修改

### 7. 重置密码 ✅
- 输入新密码重置用户密码
- 密码重置确认对话框
- 超级管理员密码不可重置

### 8. 权限控制 ✅
- 新增按钮：system:user:add
- 编辑按钮：system:user:edit
- 删除按钮：system:user:remove
- 导出按钮：system:user:export
- 重置密码：system:user:resetPwd

## 使用方式

### 1. 访问页面

路由地址：`/system/user`

### 2. 搜索用户

1. 在搜索区域输入搜索条件
2. 点击"搜索"按钮或按回车键
3. 点击"重置"清空搜索条件

### 3. 新增用户

1. 点击"新增"按钮
2. 填写用户信息
3. 点击"确定"保存

### 4. 编辑用户

1. 点击用户行的"编辑"按钮
2. 修改用户信息
3. 点击"确定"保存

### 5. 删除用户

**单个删除**：
1. 点击用户行的"删除"按钮
2. 确认删除

**批量删除**：
1. 勾选多个用户
2. 点击工具栏"删除"按钮
3. 确认删除

### 6. 修改状态

1. 点击用户状态开关
2. 状态立即生效

### 7. 重置密码

1. 点击用户的"重置密码"按钮
2. 输入新密码
3. 确认重置

## 后端接口要求

### 1. 用户列表接口

**URL**: `GET /system/user/list`

**参数**:
```
pageNum: 页码
pageSize: 每页大小
userName: 用户名称（可选）
phonenumber: 手机号码（可选）
status: 状态（可选）
beginTime: 开始时间（可选）
endTime: 结束时间（可选）
```

**返回格式**:
```json
{
  "code": 200,
  "msg": "查询成功",
  "total": 100,
  "rows": [
    {
      "userId": 1,
      "userName": "admin",
      "nickName": "管理员",
      "phonenumber": "13800138000",
      "status": "0",
      "createTime": "2024-01-01 00:00:00",
      "dept": {
        "deptId": 103,
        "deptName": "研发部门"
      }
    }
  ]
}
```

### 2. 新增用户接口

**URL**: `POST /system/user`

**参数**:
```json
{
  "userName": "test",
  "nickName": "测试用户",
  "password": "123456",
  "phonenumber": "13800138001",
  "userEmail": "test@example.com",
  "sex": "0",
  "status": "0",
  "remark": "测试"
}
```

### 3. 修改用户接口

**URL**: `PUT /system/user`

**参数**: 同新增用户

### 4. 删除用户接口

**URL**: `DELETE /system/user/{userId}`

### 5. 修改状态接口

**URL**: `PUT /system/user/changeStatus`

**参数**:
```json
{
  "userId": 1,
  "status": "0"
}
```

### 6. 重置密码接口

**URL**: `PUT /system/user/resetPwd`

**参数**:
```json
{
  "userId": 1,
  "password": "123456"
}
```

## 注意事项

### 1. 超级管理员保护

- userId = 1 的用户为超级管理员
- 不可删除
- 不可修改状态
- 不可重置密码

### 2. 权限控制

- 所有操作按钮都使用Auth组件进行权限控制
- 无权限的按钮自动隐藏

### 3. 表单验证

- 用户昵称必填
- 用户名称必填且只能包含字母数字下划线
- 新增时密码必填
- 编辑时密码留空表示不修改

### 4. 数据安全

- 密码传输使用加密（后端处理）
- 敏感操作需要二次确认
- 删除操作不可恢复
