### ✅ 3. 权限控制功能

**实现内容**:
- 创建权限工具函数 `src/utils/permission.ts`
- 创建权限Hook `src/hooks/usePermission.ts`
- 创建权限组件 `src/components/Auth/index.tsx`
- 支持页面级和按钮级权限控制

**三种使用方式**:

#### 方式1: Auth组件（推荐）
```tsx
<Auth permission="system:user:add">
  <Button>新增用户</Button>
</Auth>
```

#### 方式2: usePermission Hook
```tsx
const { hasPermission } = usePermission()

{hasPermission('system:user:add') && <Button>新增</Button>}
```

#### 方式3: 工具函数
```tsx
import { hasPermi } from '@/utils/permission'

if (hasPermi('system:user:add')) {
  // 有权限
}
```

**效果**:
- 按钮自动隐藏/显示
- 支持权限组合验证（and/or）
- 支持角色验证
- 首页展示权限信息和示例

## 性能优化

### 1. 路由懒加载
使用React.lazy实现组件懒加载，减少首屏加载时间。

### 2. 权限缓存
权限数据存储在Zustand store，自动缓存。

### 3. 菜单优化
使用useMemo避免不必要的重新渲染。
