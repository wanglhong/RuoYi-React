# 动态路由和权限控制使用指南

## 概述

本项目已实现完整的动态路由加载和权限控制功能，包括：
- ✅ 动态路由加载
- ✅ 侧边栏菜单动态渲染
- ✅ 页面级权限控制
- ✅ 按钮级权限控制

---

## 一、动态路由

### 1. 工作原理

```
后端返回路由数据
    ↓
filterAsyncRouter转换
    ↓
生成React Router路由
    ↓
渲染页面
```

### 2. 后端路由格式

```json
{
    "msg": "操作成功",
    "code": 200,
    "data": [
        {
            "name": "System",
            "path": "/system",
            "component": "Layout",
            "meta": {
                "title": "系统管理",
                "icon": "system"
            },
            "children": [
                {
                    "name": "User",
                    "path": "user",
                    "component": "system/user/index",
                    "meta": {
                        "title": "用户管理",
                        "icon": "user"
                    }
                }
            ]
        }
    ]
}
```

### 3. 组件路径映射

组件路径会自动映射到 `src/views/` 下的文件：

```
"system/user/index" → src/views/system/user/index.tsx
"monitor/online" → src/views/monitor/online.tsx
```

### 4. 特殊组件

- `Layout`: 主布局组件
- `ParentView`: 父级视图组件

## 二、侧边栏菜单

### 1. 自动渲染

侧边栏菜单会根据后端返回的路由数据自动渲染。

### 2. 图标映射

支持以下图标：

```typescript
home, system, monitor, tool, user, peoples, menu, dict, log, online, job, druid, server, cache, form, link
```

### 3. 隐藏菜单

在路由meta中设置 `hidden: true` 可以隐藏菜单项：

```json
{
    "path": "/profile",
    "meta": {
        "hidden": true
    }
}
```

## 三、权限控制

### 1. 权限标识

权限标识格式：`模块:资源:操作`

示例：
- `system:user:add` - 新增用户
- `system:user:edit` - 编辑用户
- `system:user:remove` - 删除用户
- `system:user:list` - 查看用户列表

### 2. 超级权限

`*:*:*` 表示拥有所有权限

### 3. 使用方式

#### 方式1: Auth组件（推荐）

```tsx
import Auth from '@/components/Auth'

// 单个权限
<Auth permission="system:user:add">
  <Button type="primary">新增用户</Button>
</Auth>

// 多个权限（任意一个）
<Auth permission={['system:user:add', 'system:user:edit']} mode="or">
  <Button>操作</Button>
</Auth>

// 角色验证
<Auth role="admin">
  <Button>管理员操作</Button>
</Auth>

// 多个角色
<Auth role={['admin', 'common']} mode="or">
  <Button>操作</Button>
</Auth>
```

#### 方式2: usePermission Hook

```tsx
import { usePermission } from '@/hooks'

const MyComponent = () => {
  const { hasPermission, hasRole } = usePermission()

  return (
    <div>
      {hasPermission('system:user:add') && (
        <Button type="primary">新增用户</Button>
      )}

      {hasRole('admin') && (
        <Button>管理员功能</Button>
      )}
    </div>
  )
}
```

#### 方式3: 工具函数

```tsx
import { hasPermi, hasRole } from '@/utils/permission'

// 权限判断
if (hasPermi('system:user:add')) {
  // 有权限
}

// 角色判断
if (hasRole('admin')) {
  // 是管理员
}

// 任意一个权限
if (hasPermiOr(['system:user:add', 'system:user:edit'])) {
  // 有任意一个权限
}

// 所有权限
if (hasPermiAnd(['system:user:add', 'system:user:edit'])) {
  // 有所有权限
}
```

## 四、完整示例

### 1. 用户管理页面

```tsx
import React from 'react'
import { Button, Space } from 'antd'
import { PlusOutlined, EditOutlined, DeleteOutlined } from '@ant-design/icons'
import Auth from '@/components/Auth'
import { usePermission } from '@/hooks'

const UserManagement: React.FC = () => {
  const { hasPermission } = usePermission()

  return (
    <div>
      {/* 工具栏 */}
      <Space style={{ marginBottom: 16 }}>
        <Auth permission="system:user:add">
          <Button type="primary" icon={<PlusOutlined />}>
            新增
          </Button>
        </Auth>

        <Auth permission="system:user:edit">
          <Button icon={<EditOutlined />}>
            编辑
          </Button>
        </Auth>

        <Auth permission="system:user:remove">
          <Button danger icon={<DeleteOutlined />}>
            删除
          </Button>
        </Auth>
      </Space>

      {/* 表格 */}
      <Table
        columns={[
          {
            title: '用户名',
            dataIndex: 'username',
          },
          {
            title: '操作',
            render: (record) => (
              <Space>
                <Auth permission="system:user:edit">
                  <Button type="link" onClick={() => handleEdit(record)}>
                    编辑
                  </Button>
                </Auth>

                <Auth permission="system:user:remove">
                  <Button type="link" danger onClick={() => handleDelete(record)}>
                    删除
                  </Button>
                </Auth>
              </Space>
            ),
          },
        ]}
      />
    </div>
  )
}
```

### 2. 条件渲染

```tsx
import { usePermission } from '@/hooks'

const MyComponent = () => {
  const { hasPermission, hasRole, filterByPermission } = usePermission()

  // 方式1: 条件渲染
  const showAddButton = hasPermission('system:user:add')

  // 方式2: 过滤菜单
  const menuItems = [
    { key: 'add', label: '新增', permission: 'system:user:add' },
    { key: 'edit', label: '编辑', permission: 'system:user:edit' },
    { key: 'delete', label: '删除', permission: 'system:user:remove' },
  ]

  const filteredMenu = filterByPermission(menuItems)

  return (
    <div>
      {showAddButton && <Button>新增</Button>}
      
      {filteredMenu.map(item => (
        <Button key={item.key}>{item.label}</Button>
      ))}
    </div>
  )
}
```

## 五、API文档

### usePermission Hook

```typescript
const {
  permissions,           // 当前用户权限列表
  roles,                 // 当前用户角色列表
  hasPermission,         // (permission: string) => boolean
  hasPermissionOr,       // (permissions: string[]) => boolean
  hasPermissionAnd,      // (permissions: string[]) => boolean
  hasRole,               // (role: string) => boolean
  hasRoleOr,             // (roles: string[]) => boolean
  hasRoleAnd,            // (roles: string[]) => boolean
  filterByPermission,    // <T extends { permission?: string }>(items: T[]) => T[]
  filterByRole,          // <T extends { role?: string }>(items: T[]) => T[]
} = usePermission()
```

### Auth组件

```typescript
interface AuthProps {
  children: React.ReactNode
  permission?: string | string[]   // 权限标识
  role?: string | string[]         // 角色标识
  mode?: 'or' | 'and'              // 验证模式，默认'or'
}
```

## 六、最佳实践

### 1. 权限标识命名规范

```
模块:资源:操作
```

示例：
- `system:user:add` - 系统模块-用户资源-新增操作
- `system:role:edit` - 系统模块-角色资源-编辑操作
- `monitor:online:force` - 监控模块-在线用户-强制退出

### 2. 权限分组

建议按模块分组管理权限：

```typescript
// constants/permission.ts
export const USER_PERMISSIONS = {
  ADD: 'system:user:add',
  EDIT: 'system:user:edit',
  REMOVE: 'system:user:remove',
  LIST: 'system:user:list',
  EXPORT: 'system:user:export',
  IMPORT: 'system:user:import',
}

// 使用
<Auth permission={USER_PERMISSIONS.ADD}>
  <Button>新增</Button>
</Auth>
```

### 3. 权限缓存

权限数据已存储在Zustand store中，会自动缓存。

### 4. 权限更新

当用户权限变更时，需要重新获取用户信息：

```typescript
const { getUserInfo } = useUserStore()

// 重新获取用户信息（包括权限）
await getUserInfo()
```

## 七、常见问题

### Q1: 权限不生效？

检查：
1. 后端是否正确返回权限列表
2. 权限标识是否正确
3. 是否有超级权限 `*:*:*`

### Q2: 菜单不显示？

检查：
1. 后端是否返回路由数据
2. 路由meta是否设置 `hidden: true`
3. 组件路径是否正确

### Q3: 动态路由加载失败？

检查：
1. 组件文件是否存在
2. 文件扩展名是否正确（.tsx）
3. 组件路径格式是否正确
