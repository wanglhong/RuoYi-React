## 问题1: 验证码图片不显示

### 问题描述
验证码图片无法显示

### 原因
API返回格式理解错误，字段在顶层，不在`data`对象中

### 解决方案
修改验证码接口的类型定义和数据处理：

```typescript
// src/api/login.ts
export interface CaptchaInfo {
  msg: string
  img: string
  code: number
  captchaEnabled: boolean
  uuid: string
}

// src/views/login/index.tsx
const { captchaEnabled, img, uuid, code } = res  // 直接从顶层获取
if (code !== 200) {
  throw new Error(res.msg || '验证码获取失败')
}
setCodeUrl('data:image/gif;base64,' + img)
```

## 问题2: 登录失败 - Cannot read properties of undefined (reading 'token')

### 问题描述
点击登录按钮后报错：`Cannot read properties of undefined (reading 'token')`

### 错误信息
```
TypeError: Cannot read properties of undefined (reading 'token')
```

### 原因
代码尝试访问`res.data.token`，但API返回的token字段在顶层：

```json
{
    "msg": "操作成功",
    "code": 200,
    "token": "eyJhbGciOiJIUzUxMiJ9..."
}
```

### 解决方案

#### 1. 修改API接口类型定义

```typescript
// src/api/login.ts
export interface LoginResult {
  msg: string
  code: number
  token: string  // token在顶层
}

export function login(data: LoginParams): Promise<LoginResult> {
  return request({
    url: '/login',
    method: 'post',
    data
  })
}
```

#### 2. 修改Store中的处理逻辑

```typescript
// src/store/modules/user.ts
loginAction: async (loginForm: LoginParams) => {
  try {
    const res = await login(loginForm)
    
    // 检查状态码
    if (res.code !== 200) {
      throw new Error(res.msg || '登录失败')
    }
    
    // 直接从顶层获取token，不是res.data.token
    const token = res.token
    if (!token) {
      throw new Error('登录返回token为空')
    }
    
    set({ token })
    setToken(token)
    console.log('登录成功, token已保存')
  } catch (error) {
    throw error
  }
}
```

## 若依API返回格式特点

### 标准格式
```json
{
  "code": 200,
  "msg": "操作成功",
  "field1": "value1",
  "field2": "value2"
}
```

**特点**:
- ✅ 字段在顶层，不嵌套在`data`对象中
- ✅ `code: 200` 表示成功
- ✅ `msg` 提供提示信息
- ✅ 业务数据直接作为顶层字段

### 对比其他系统
```json
// 其他系统的格式（嵌套data）
{
  "code": 200,
  "msg": "成功",
  "data": {
    "token": "xxx",
    "user": {}
  }
}
```

## 注意事项

1. **所有接口都遵循这个格式**
   - 登录、验证码、获取用户信息等
   - 字段都在顶层，不在data中

2. **状态码判断**
   - `code === 200` 表示成功
   - 其他值表示失败

3. **错误处理**
   - 检查code状态码
   - 读取msg字段获取错误信息

4. **Token管理**
   - 登录成功后保存到Cookie
   - 每次请求自动添加到Header
   - Token过期自动跳转登录页
