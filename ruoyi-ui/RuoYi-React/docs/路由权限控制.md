# 路由权限控制

## 实现说明

本项目已实现基于React Router 6的路由权限控制,参考RuoYi-Vue3的实现方式。

## 主要功能

### 1. 路由守卫 (AuthGuard)

**位置**: `src/components/AuthGuard/index.tsx`

**功能**:
- 未登录用户访问受保护页面时,自动跳转到登录页
- 登录后自动获取用户信息
- 显示加载状态
- 使用NProgress显示路由跳转进度条

### 2. 白名单机制

以下路由无需登录即可访问:
- `/login` - 登录页
- `/register` - 注册页

### 3. Token管理

**位置**: `src/utils/auth.ts`

**功能**:
- 使用Cookies存储token
- 提供 `getToken()`, `setToken()`, `removeToken()` 方法

### 4. 用户状态管理

**位置**: `src/store/modules/user.ts`

**功能**:
- 使用Zustand管理用户状态
- 提供 `loginAction()`, `getUserInfo()`, `logoutAction()` 方法
- 持久化token到localStorage

### 5. 登录页面

**位置**: `src/views/login/index.tsx`

**功能**:
- 用户名、密码、验证码登录
- 记住密码功能
- 登录后跳转到原访问页面或首页

## 使用方式

### 1. 添加新的公开路由

在 `src/App.tsx` 中添加路由,并确保在AuthGuard外或在白名单中:

```tsx
<Route
  path="/public-page"
  element={<PublicPage />}
/>
```

### 2. 添加新的受保护路由

在主布局路由下添加:

```tsx
<Route
  path="/"
  element={
    <AuthGuard>
      <Layout />
    </AuthGuard>
  }
>
  <Route path="new-page" element={<NewPage />} />
</Route>
```

### 3. API接口调用

使用封装好的request工具:

```typescript
import request from '@/utils/request'

// 调用接口
request({
  url: '/api/xxx',
  method: 'get'
})
```

request会自动:
- 添加token到请求头
- 处理响应错误
- 处理401未授权情况

## 路由流程

```
用户访问 -> AuthGuard检查
  ├─ 白名单路由 -> 直接访问
  ├─ 无token -> 跳转登录页
  ├─ 有token无用户信息 -> 获取用户信息 -> 显示页面
  └─ 有token有用户信息 -> 显示页面
```

## 注意事项

1. 确保后端API接口已实现以下接口:
   - `POST /login` - 登录接口
   - `GET /getInfo` - 获取用户信息
   - `GET /captchaImage` - 获取验证码
   - `POST /logout` - 退出登录

2. 后端需要支持CORS跨域配置

3. 生产环境需要修改 `vite.config.ts` 中的代理配置
