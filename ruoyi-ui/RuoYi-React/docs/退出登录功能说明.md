# 退出登录功能说明

## 功能概述

实现了完整的退出登录功能，包括：
- 确认对话框
- 调用后端退出接口
- 清除本地数据
- 跳转到登录页

---

## 实现流程

```
用户点击退出登录
    ↓
显示确认对话框
    ↓
用户确认
    ↓
调用logout接口
    ↓
清除用户数据
    ↓
清除权限数据
    ↓
跳转登录页
```

## 核心代码

### 1. Navbar组件

**位置**: `src/layout/components/Navbar.tsx`

```tsx
import { Modal, message } from 'antd'
import { useUserStore, usePermissionStore } from '@/store'

const { logoutAction } = useUserStore()
const { resetPermission } = usePermissionStore()

// 退出登录
const handleLogout = () => {
  Modal.confirm({
    title: '提示',
    icon: <ExclamationCircleOutlined />,
    content: '确定注销并退出系统吗？',
    okText: '确定',
    cancelText: '取消',
    onOk: async () => {
      try {
        // 调用退出登录接口
        await logoutAction()
        
        // 清除权限数据
        resetPermission()
        
        message.success('退出成功')
        
        // 跳转到登录页
        navigate('/login', { replace: true })
      } catch (error: any) {
        // 即使退出失败，也要清除本地数据并跳转
        message.error(error.message || '退出失败')
        navigate('/login', { replace: true })
      }
    }
  })
}
```

### 2. User Store

**位置**: `src/store/modules/user.ts`

```typescript
logoutAction: async () => {
  try {
    await logout()  // 调用后端接口
  } finally {
    removeToken()   // 清除token
    set({
      token: '',
      name: '',
      avatar: '',
      roles: [],
      permissions: []
    })
  }
}
```

### 3. Permission Store

**位置**: `src/store/modules/permission.ts`

```typescript
resetPermission: () => {
  set({
    routes: [],
    dynamicRoutes: [],
    sidebarRouters: [],
    isLoaded: false
  })
}
```

## 功能细节

### 1. 确认对话框

使用Ant Design的Modal.confirm组件：

```tsx
Modal.confirm({
  title: '提示',
  icon: <ExclamationCircleOutlined />,
  content: '确定注销并退出系统吗？',
  okText: '确定',
  cancelText: '取消',
  onOk: async () => {
    // 退出登录逻辑
  }
})
```

### 2. 错误处理

即使后端接口调用失败，也会清除本地数据并跳转：

```typescript
try {
  await logoutAction()
  message.success('退出成功')
} catch (error: any) {
  message.error(error.message || '退出失败')
  // 仍然跳转到登录页
} finally {
  navigate('/login', { replace: true })
}
```

### 3. 路由跳转

使用`replace: true`防止用户通过浏览器后退按钮回到已登出页面：

```typescript
navigate('/login', { replace: true })
```

### 4. 清除数据

退出登录时会清除：
- Token (Cookie)
- 用户信息 (name, avatar)
- 角色信息 (roles)
- 权限信息 (permissions)
- 路由信息 (routes, sidebarRouters)

## API接口

### 退出登录接口

**URL**: `POST /logout`

**Headers**:
```
Authorization: Bearer {token}
```

**返回格式**:
```json
{
  "code": 200,
  "msg": "操作成功"
}
```

**注意**: 即使接口调用失败，前端也会清除本地数据并跳转到登录页。

## 常见问题

### Q1: 退出后仍能访问页面？

**检查**:
1. 路由守卫是否正常工作
2. Token是否已清除
3. 是否使用了navigate的replace模式

### Q2: 退出后权限数据未清除？

**解决**:
确保调用了`resetPermission()`清除权限store。

### Q3: 退出接口报错怎么办？

**说明**:
即使接口报错，前端也会清除本地数据并跳转，保证用户能够正常退出。
