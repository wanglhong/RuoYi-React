# 验证码功能说明

## 问题
登录页面的验证码图片无法显示

## 解决方案

### 1. 开发环境 Mock 验证码
在开发环境下,如果后端API不可用,会自动生成一个简单的Canvas验证码图片作为Mock数据。

**特点**:
- 随机生成4位字母数字验证码
- 添加干扰线
- 每次点击刷新验证码
- 在控制台输出验证码内容(仅开发环境)

### 2. 生产环境降级处理
在生产环境下:
- API调用失败时显示错误提示
- 显示占位图,用户可以点击刷新

### 3. 错误处理增强
- 添加图片加载错误处理(`onError`)
- 图片加载失败自动重新获取验证码
- 添加占位符显示,提升用户体验

## 使用方式

### 开发环境
直接运行 `npm run dev`,验证码会自动生成Mock数据

### 生产环境
需要配置后端API接口: `GET /captchaImage`

**返回格式**:
```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "captchaEnabled": true,
    "uuid": "唯一标识",
    "img": "base64编码的图片"
  }
}
```

### 禁用验证码
如果后端返回:
```json
{
  "code": 200,
  "data": {
    "captchaEnabled": false
  }
}
```
则登录表单不会显示验证码输入框。

## 验证码样式
- 宽度: 120px
- 高度: 40px
- 边框: 1px solid #d9d9d9
- hover效果: 蓝色边框
- 点击刷新: 点击图片重新获取验证码

## 注意事项

1. **开发环境**: Mock验证码仅供前端开发使用,不会进行真实验证
2. **生产环境**: 必须配置正确的后端API
3. **验证逻辑**: 登录时需要将验证码和uuid一起发送给后端验证
4. **安全性**: 生产环境请务必使用后端生成的验证码

## 调试

打开浏览器控制台可以看到:
- "使用Mock验证码" - 表示使用了Mock数据
- "Mock验证码: XXXX" - 显示验证码内容(开发环境)
- "获取验证码失败" - API调用失败
- "验证码图片加载失败" - 图片加载错误
