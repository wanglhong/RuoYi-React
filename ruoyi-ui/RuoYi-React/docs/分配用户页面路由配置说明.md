# 分配用户页面路由配置说明

## 概述

已将"分配用户"功能从弹窗页面改为独立页面，需要在后端数据库中添加相应的路由配置。

## 文件变更

### 新增文件
- `src/views/system/role/authUser.tsx` - 分配用户独立页面组件

### 修改文件
- `src/views/system/role/index.tsx` - 移除分配用户弹窗相关代码，改为路由跳转

## 简化配置（仅添加页面路由）

如果只需要添加页面路由而不需要额外的按钮权限控制，可以只添加主菜单：

```sql
-- 1. 先查询角色管理的 menu_id
SELECT menu_id, parent_id 
FROM sys_menu 
WHERE menu_name = '角色管理' AND menu_type = 'C';

-- 2. 插入分配用户菜单 (将 parent_id 替换为上面查询的结果)
INSERT INTO sys_menu (
    menu_name, 
    parent_id, 
    order_num, 
    path, 
    component, 
    is_frame, 
    is_cache, 
    menu_type, 
    visible, 
    status, 
    perms, 
    icon, 
    remark, 
    create_by, 
    create_time
) VALUES (
    '分配用户',
    <parent_id 从上一步查询获取>,
    4,
    'authUser/:roleId',
    'system/role/authUser',
    1,
    0,
    'C',
    '0',
    '0',
    'system:role:authUser',
    'user',
    '分配用户页面',
    'admin',
    NOW()
);
```

## 页面访问方式

配置完成后，可以通过以下方式访问分配用户页面：

```
/system/role/authUser/1  // 访问角色 ID 为 1 的分配用户页面
```

在角色管理页面点击"分配用户"按钮后，会自动跳转到对应的分配用户页面。

## 注意事项

1. **parent_id 配置**：必须使用角色管理菜单的实际 `menu_id` 作为父 ID
2. **order_num 配置**：显示顺序，数字越小越靠前
3. **component 路径**：必须与 `src/views/system/role/authUser.tsx` 路径匹配
4. **path 路由**：使用 `:roleId` 作为动态参数
5. **权限标识**：`perms` 字段需要在后端接口权限中配置

## 后端接口权限

确保后端已经配置了以下接口权限：
- `system:role:authUser` - 访问分配用户页面
- `system:role:add` - 添加用户权限
- `system:role:remove` - 取消授权权限

## 测试步骤

1. 执行 SQL 脚本添加菜单
2. 重启后端服务（如有必要）

4. 点击任意角色右侧的"分配用户"按钮
5. 验证是否正确跳转到独立页面
6. 验证"返回"按钮是否能正确返回角色管理页面
